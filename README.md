About
=====

If you are here from Google Summer of Code 2025, [see the final status report (including all patches submitted) for GSoC 2025!](https://kolmanthomas.github.io/blog/2025/08/31/gsoc-log-entry-no-7/). If this link doesn't work, try [going here](gsoc.md).

If you want an overview of what Chebfun is, [visit the Chebfun website!](https://www.chebfun.org/).

If you want to see the current status of Chebfun on Octave, [see the Octave notes!](octave_notes.md).

[View the official Chebfun on Octave repository.](https://github.com/cbm755/chebfun/)

[View the original Chebfun repository.](https://github.com/chebfun/chebfun)

This is the repository for a Google Summer of Code 2025 project to port Chebfun from MATLAB to GNU Octave. Since the project is still active, this repository is still being updated regularly.
